# Ordy Blagajna for Windows

Installer downloads and automatic updates for **Ordy Blagajna**, the Windows app
that prints [Ordy](https://ordy.menu) receipts, kitchen tickets and close-outs
on a restaurant's own receipt printer.

Download: https://ordy.menu/app/ordy-blagajna-setup.exe

This repository holds only the release files.
